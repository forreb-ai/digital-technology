Software Engineering

Design • Develop • Test • Evaluate

About This Pathway

Software Engineering focuses on solving real-world problems through programming. Students investigate a need, design a software solution, develop code, test their outcome and evaluate its effectiveness for users.

What You Will Learn

  • Programming concepts and coding techniques
  • Computational thinking
  • Algorithms and problem solving
  • Software design processes
  • Testing and debugging
  • User-centred development

Possible Projects

  • Quiz application
  • Educational game
  • Revision tool
  • Interactive story
  • Study planner
  • School-based software solution
  • Simulation or modelling software
